# Sneha AI

Sneha AI is an AI-powered education, productivity, health, career and creator platform.

## Features

- AI Mentor
- Notes Library
- PDF Learning
- RGPV Test Mode
- Coding Lab
- Progress Tracker
- Health & Wellness
- Scholarships
- Exam Alerts
- Creator Studio
- Telegram Bot
- Admin Panel

## Tech Stack

Frontend:
- Next.js
- Tailwind CSS

Backend:
- Node.js
- Express.js

Database:
- Supabase PostgreSQL

Deployment:
- Render

## Modules

- Education Hub
- Coding Lab
- Health Hub
- Career Radar
- Creator Studio
- Admin Dashboard
